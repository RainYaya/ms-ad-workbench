## doubts[]
1. **【bikuri 拍板】MAZG101W050 の断言不在＋completeErrorCode 参数不一致**: 本Case核心确认（表示内容3）が自动化的に一度も検証されない。且 auto.json 的 completeErrorCode=W047 与别纸 W050 不一致——将来谁把错误码断言接上时若引用该参数会断言错码。拍板: ①给本模板组加 W050 断言+修正参数，②或明确"迁移のみ自动化、排他/消息は真机确认"。
2. **他端末前提の不在**: r20「事務S のユーザで他端末ログインし他端末で更新」が自動化内に無く、排他制御の前提が成立しないまま送り状印刷を押している。真机手順として人が介在する前提か要確認（004 doubts[2] 同型）。
3. **BLK-SGL-90299E43 の goto は画面状態をリセットする**: block は AMA04 を再 goto してから送り状印刷を押す——mock の静的ページでは無害だが、真机 run のまま同じ积木を流すと「更新押下後のセッション画面」ではなく素の AMA04 に飛ぶ可能性（セッション/照会ID コンテキストが切れる）。live 移行時の积木設計要確認。
4. **明細番号未入力差分**: 操作内容1 は 証券番号+明細番号 を要求するが filter 积木は証券番号のみ fill。真机の検索結果が別紙（1 件ヒット想定）と一致するかは真机确认事項。
5. 事前準備データ（AZ11103/0000000003、不備情報 T007 要/T001 否）を登録する自動化手順が本Caseに無く、「事前準備で登録したデータが表示」の根拠が自動化内に無い（004 doubts[3] 同型）。
6. user="?"/pointCheck="?"（auto.json 占位）: 未接线のため実害なし、残余清掃対象。

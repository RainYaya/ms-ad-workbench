# 0002 — 本与自建流程是两种身份，共用引擎

手顺可以只是模板，人也可以自己画流程；但一旦自建流程混进试验结果，"这一步对着手顺哪一行"就断了，证据链和试验结论一起失效。因此一个流程必须有身份：**本**由手顺派生、每步带 Excel 行号、期望不可改、计入结合试验；**自建流程**由人编写、无行号、期望自定、不计入试验。两者共用同一套 17 原语、控件库和绑定表。

**Considered Options**

- 统一成"流程"，行号可选：报告无法区分"跑通了"和"按手顺跑对了"。
- 自建流程也强制行号：自建就失去了意义。

**Consequences**

- 目录分离：生成器只写 `flows/books/`，永不碰 `flows/custom/`。
- 报告按身份分栏，mock 绿的自建流程不得计入 450/1,371 本进度。
- 从本 fork 成自建流程时，行号降级为注释，期望转为用户定义。

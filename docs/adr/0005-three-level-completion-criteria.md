# 0005 — 完成分三级，mock 绿不算完成

一本"做对了"需要同时满足三级：L0 静态（编译 0 error、0 条未确认绑定、步骤数 = 手顺操作行数）、L1 mock（全行 done、`evidencePolicy: all`、0 fail）、L2 真机（每个画面至少一本在真实 SUT 上跑通并存证）。mock 只证明操作链能走通，不证明业务对；画面没有真实前端 HTML 的本（约 9%）不生成，只进未覆盖清单。

**Considered Options**

- 以 mock 全绿为完成：过去 450 本"全部通过"正是 mock-only，没有业务真值。
- 只做真机：1,371 本 × 每本数十步，人工与时间都不可行。

**Consequences**

- 报告必须分别给出 L0 / L1 / L2 的数字，禁止合并成一句"跑通"。
- L2 以画面为抽样单位（每画面至少 1 本），而不是以本为单位。
- 未覆盖清单本身是交付物，不是失败。

# 0003 — 用显式绑定表取代模糊匹配

**Status**: accepted（取代 `docs/rpa/00-DECISIONS.md` D5 中"模糊匹配要求重叠度 ≥60%"）

19,056 行操作只对应 452 条「画面 + 措辞」绑定，其中 137 条能被确定性规则命中、29 条是指令（fillAll）、16 条是行链接，约 220 条需要人看一眼。我们把这些绑定固化成跨本共享的绑定表，只允许三种解析：模板（标签精确等于 X，命中数必须恰为 1）、指令（措辞本身就是动作）、显式绑定。模糊匹配全部删除——它曾在「選択欄」上错配到「選択」按钮，本质是猜。

**Considered Options**

- 保留模糊作为兜底：覆盖率好看，但无法区分"对"和"看起来对"，违反 R0/D5 的红线。
- 逐本人工绑定：1,371 本 × 平均 14 步，不可行。

**Consequences**

- 未确认绑定会阻塞生成（fail-stop），而不是降级为 `pendingRuntime` 警告。
- 每次解析记录 `{row, screen, phrase, rule, control}`，可回溯。
- 绑定维护成本从 19,056 行降到 452 条，新增手顺措辞时才需要新增绑定。

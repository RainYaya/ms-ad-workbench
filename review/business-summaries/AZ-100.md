## TPL-AZ-100-05-003（1 本）

**業務**：不備一覧検索 → 更新画面開 → 開発者ツールで application_form_id を改ざん → 更新押下 → システムエラー（親画面）確認

**画面流**：メニュー → 不備一覧画面 → 不備内容入力画面－更新 →（開発者ツール）→ システムエラー画面（親画面）

**操作**：
1. メニュー「検索」→ 不備一覧画面（初期値，目視確認）
2. 「検索」→ 数据表示（目視確認）
3. 点「No.」リンク → 不備内容入力画面－更新（画面HC）
4. 【非浏览器（開発者ツール）】「F12」で開発者ツールを開く → ctrl+f で application_form_id を検索（画面HC：開発者ツールに表示）
5. 【非浏览器（開発者ツール）】application_form_id の value 値を削除（画面HC：値が変更されていること）
6. 「更新」→ システムエラー画面（親画面）に遷移（画面HC）
7. 期待输出エラーメッセージ MAZG000E001（画面HC）

**同模板差异**：単一（AZ-100-05-003：無個別パラメータ，事前登録データは別紙参照）

**自动化形态**：步 1–3、6–7 = 浏览器块（BLK-AZ-MENU-SEARCH-LIST / BLK-AUTO-9EB5A282 可复用）；步 4–5 = 半自动（F12 開発者ツールの DOM 操作は通常のセレクタ操作と異なるため CDP 等での実装が必要）；整体为「浏览器为主 + 開発者ツール步半自动」。

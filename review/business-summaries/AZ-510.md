# 業務要覧 —— AZ-510 分類（営業連携メール通知）

> 1 模板 · 1 本。焦点：営業連携ボタンからメール通知先選択（ポップアップ）→通知実行→メール受信とメール内リンク遷移の確認。格式基准：AZ-110.md。

---

## TPL-AZ-510-01-005（1 本）

**業務**：不備一覧検索 → 不備内容入力（更新）→ 営業連携 → メール通知先選択・検索・通知 → メール受信確認 → メール内リンクで回答画面へ遷移（事務(貨物)以外・AD定義）

**画面流**：メニュー → 不備一覧画面 → 不備内容入力画面-更新 → メール通知先選択画面（ポップアップ）→ 不備内容入力画面-更新 →（メール）→ 不備内容入力・回答画面

**操作**：
1.「検索」押下 → 不備一覧画面 初期値表示
2. 各項目に入力（証券番号=AZ51001、明細番号=0000000005）→「検索」押下 →「No.」リンク押下 → 不備内容入力画面-更新に遷移（表示内容１：依頼区分=照会、点検区分=営業）
3.「営業連携」押下 → メール通知先選択画面がポップアップ表示されること
4. 各項目に入力（氏名=黒川）→「検索」押下 → 検索結果に対象ユーザー（黒川京子）が検索されること
5.「No.」クリック → 通知先一覧に対象ユーザー（黒川京子）が追加されること
6.「通知する」押下 →「OK」押下 → メール通知先選択画面が閉じること
7. 不備内容入力画面-更新で営業連携が行われ、連携が「営業」になること（画面HC）
8. 【非浏览器】メール送信ログ確認（機能呼出前後のログ MAZG101I5…、APログ）
9. 【非浏览器→半自动】営業連携通知メールの受信確認 → メール内リンク押下 → 不備内容入力・回答画面へ適切に遷移すること → 不備内容入力画面-更新が正しく表示されること

※ログイン：AD用户かつ点検区分が「営業」のユーザー。登録内容：証券番号=AZ51001、明細番号=0000000005、依頼区分=照会、点検区分=営業。

**同模板差异**：単一（AZ-510-01-005：証券番号=AZ51001、明細番号=0000000005、点検区分=営業、通知先検索氏名=黒川）

**自动化形态**：步 1–7 = 浏览器块（BLK-AZ-MENU-SEARCH-LIST / BLK-AZ-LIST-FILTER-OPEN-UPDATE / BLK-AUTO-2739DA75 営業連携→通知先検索→通知→連携HC確認 / BLK-SGL-FF4BE5F2 ポップアップ操作）；步 8 = 人工（メール送信ログ APログ在浏览器外）；步 9 = 半自动（メール受信確認＋メール内リンク点击=浏览器外邮件客户端→链接打开回答画面）。→ 整体半自动。

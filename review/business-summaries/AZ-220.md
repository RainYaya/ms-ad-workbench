# 業務要覧 —— AZ-220 分類（代理店不備一覧：検索条件/参照可能代理店）

> 2 模板 · 2 本。焦点：代理店不備一覧画面の初期表示における参照可能代理店テーブルとの突合（データあり/なしの2系統）。格式基准：AZ-110.md。

---

## TPL-AZ-220-01-003（1 本）

**業務**：代理店不備一覧 初期表示 → 参照可能代理店テーブル突合 → 検索 → 件数一致確認（ログイン後データ表示あり）

**画面流**：メニュー → 代理店　不備一覧画面（初期表示）→ 同画面（検索結果）

**操作**：
1. 代理店不備一覧画面を初期表示（ログイン直後、検索条件未入力の状態）
2. 【非浏览器】参照可能代理店テーブルをダンプ（DBダンプ）し、ログインユーザーが参照できる代理店のデータ範囲を把握
3. 各項目に入力 →「検索」押下（検索結果一覧が表示される）
4. 検索結果件数が、参照可能代理店テーブル上のデータ件数と一致すること（画面HC）

**同模板差异**：単一（AZ-220-01-003：パラメータなし＝検索条件は共通初期値、期待=データ表示あり）

**自动化形态**：步 1、3、4 = 浏览器块（BLK-AZ-AGT-LIST-INITIAL 初期表示＋検索＋件数HC確認）；步 2 = 人工（参照可能代理店テーブル DBダンプ在浏览器外）。→ 整体半自动。

## TPL-AZ-220-01-004（1 本）

**業務**：代理店不備一覧 初期表示 → 参照可能代理店テーブル突合 → 警告メッセージ確認（ログイン後データ表示なし）

**画面流**：メニュー → 代理店　不備一覧画面（初期表示・0件）

**操作**：
1. 代理店不備一覧画面を初期表示（ログイン直後、検索条件未入力の状態）
2. 【非浏览器】参照可能代理店テーブルをダンプ（DBダンプ）し、参照可能データが 0 件であることを確認
3. 初期表示時点でメッセージエリアに警告「MAZG206W100」が表示されること（画面HC）

**同模板差异**：単一（AZ-220-01-004：パラメータなし、期待=データ0件＋警告表示）

**自动化形态**：步 1、3 = 浏览器块（BLK-AZ-AGT-LIST-INITIAL-EMPTY 初期表示＋警告メッセージHC確認）；步 2 = 人工（DBダンプ）。→ 整体半自动。

### 实际可用的 Edge 启动方式

Edge 155 不允许用默认 `User Data` 开 CDP；直接指定默认 profile 时端口不会监听。必须复制 profile 到非默认目录，并加 `--profile-directory=Default`：

```powershell
Get-Process msedge -ErrorAction SilentlyContinue | Stop-Process -Force
Start-Sleep -Seconds 5

$src = "$env:LOCALAPPDATA\Microsoft\Edge\User Data"
$dst = "$env:TEMP\msad-edge-copy"
if (Test-Path $dst) { Remove-Item $dst -Recurse -Force }

robocopy $src $dst /E /XD Cache "Code Cache" GPUCache "ShaderCache" "Service Worker" Crashpad /XF SingletonLock SingletonCookie SingletonSocket lockfile /R:1 /W:1 | Out-Null

$edge = @(
  'C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe',
  'C:\Program Files\Microsoft\Edge\Application\msedge.exe'
) | Where-Object { Test-Path $_ } | Select-Object -First 1

& $edge --remote-debugging-port=9223 --user-data-dir="$dst" --profile-directory=Default --no-first-run --no-default-browser-check --new-window "http://127.0.0.1:10081/mhkcmwa11/dummy.html"
```

登录 `MS-3n / 事務S`，然后：

```powershell
Invoke-RestMethod http://127.0.0.1:9223/json/version
cd C:\ms-ad-automation
powershell -ExecutionPolicy Bypass -File .\run-009.ps1 -Port 9223 -BaseUrl "http://127.0.0.1:10081/mhkcmwa11/dummy.html"
```

不要加 `-StartEdge`，也不要同时用默认 profile 和复制 profile 跑两个 Edge。

## 自动化方式（CDP）

不要再按页面手动粘贴 Console 片段。现在用 **PowerShell + Edge CDP**：

- `automation/cdp/Cdp.ps1`：CDP 连接 / 执行 JS / 等待 / popup / 截图
- `automation/cdp/start-edge.ps1`：一键启动带 CDP 的 Edge（使用复制 Profile）
- `automation/cdp/run-009.ps1`：009 的 block 1〜3
- popup 由 CDP 直接找到并操作，不需要在 popup 按 F12

### 关键限制（Edge 155）

- Edge 155 不允许用默认 `User Data` 目录开 CDP；指定默认 profile 时端口不会监听。
- 必须复制 Profile 到非默认目录，并加 `--profile-directory=Default`。
- `start-edge.ps1` 已经封装了：关闭 Edge → 首次复制 Profile → 启动 CDP。

### 下次跑法


- 如果 9223 已在跑，直接返回。

不要加 `-StartEdge`，不要用默认 Profile 再开第二个 Edge。

### 为什么之前 `$dst` 跑不起来

`$dst` 只在当时那个 PowerShell 窗口里有值。新窗口只复制 Edge 命令，`$dst` 为空，Edge 拿不到 user-data-dir，CDP 就不会开。`start-edge.ps1` 已固定 profile 路径，不需要每次设 `$dst`。

### Profile 需要每次复制吗

不需要。只有第一次或 `-RecreateProfile` 时复制。之后 `$env:TEMP\msad-edge-copy` 会保留登录 cookie；每次只是关闭 Edge，用同一个复制 Profile 重新带 CDP 启动。
